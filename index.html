Common questions

A message will not decrypt. The error explains why — usually it was encrypted to a different key than the ones on this phone. Ask the sender which key they used, or import the right one.

I have a new phone. Keys are never synced or backed up automatically. Open the backup file you saved and choose More → Restore a backup.

I forgot my backup passphrase. It cannot be recovered — that is what keeps the backup safe. If you still have the old phone, make a new backup from it.
